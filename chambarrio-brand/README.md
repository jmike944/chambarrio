# Chambarrio brand kit

Logo, icons and drop-in React components for rebranding the app from "Chamb-a lado" to **Chambarrio**.

**To implement it:** unzip this folder into the project root as `chambarrio-brand/` and paste the prompt in `CLAUDE_CODE_PROMPT.md` into Claude Code.

| File | What it's for |
|---|---|
| `BRAND.md` | Colors, type, which file to use where, and what not to do |
| `CLAUDE_CODE_PROMPT.md` | Ready-to-paste implementation instructions |
| `brand-sheet.png` | One-page overview of every asset |
| `react/ChambarrioLogo.tsx` | `ChambarrioLogo`, `ChambarrioAppIcon`, `ChambarrioMark`, `ChambarrioWordmark`, `ChambarrioPulse` |
| `logo/`, `wordmark/`, `mark/` | Vector logos in color, color-on-dark, mono-ink and mono-white |
| `app-icon/` | App icon SVGs (rounded, square, maskable, favicon, WhatsApp) |
| `png/` | PWA icons (192, 512, maskable), `apple-icon.png`, `favicon.ico`, large logo PNGs |
| `social/` | `opengraph-image.png` (1200x630) and `whatsapp-profile-640.png` |

The wordmark in the SVG files is outlined from Bricolage Grotesque ExtraBold (SIL Open Font License), so the files don't need the font installed.
